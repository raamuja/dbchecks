4. Stored procedure differences: Git vs. Qualification (PROD copy)
• Set up a process to compare stored procedures in Git against the Qualification environment, which is a copy of Production.
• The comparison shows exactly which procedures differ between the two.
• This catches code drift and mismatches before they cause problems in Production.
• It also helps when investigating slow procedures, since the differences are easy to see.

    ◦ Total of 105 stored procedures, of which about 65 are completed.

    ◦ All 116 stored procedures are completed.

6. Subnet application: slow record retrieval
• Problem: The Subnet application was slow to retrieve records in its front end.
• Diagnosis: Using SQL Optimizer and Show Plan, I found that some tables were going for full table scans.
• Testing: I created indexes in the UAT database. Records then came back within a few seconds.
• Recommendation: The optimizer was still not using the index even after update statistics, so I asked the Subnet team to force the index in their queries.
• Outcome: Their front-end tool only allows a fixed set of hard-coded statements, so the recommendation could not be applied. The team went ahead with archival instead.
• Likely question: Why archival instead of the index? The index fix was proven in UAT, but the tool's limits blocked it, so archival was the practical alternative.
